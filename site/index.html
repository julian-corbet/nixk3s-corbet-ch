nixk3s

The host is a flake, the cluster is git

Bare-metal k3s on NixOS with a fully declarative GitOps spine: nixidy renders typed Nix modules to a plain manifest tree, Argo CD reconciles it with prune + self-heal. No hand-applied YAML, no drift.

One coherent answer

  • The host is a flake. k3s server config, node labels, storage paths — all NixOS options, all reproducible.
  • Workloads are Nix too. nixidy renders to plain manifests you can read, diff, and audit; Argo CD keeps the cluster equal to git.
  • Airgapped images. Custom images imported declaratively on the host — no registry required for cluster-internal pieces.
  • Tenancy by AppProject. What manages the cluster is separated from what runs on it.

Status

Pre-alpha. The spine runs a production single-node cluster (15+ Argo applications, GPU workloads) and has survived node rebuilds and a bare-metal migration. The generalized modules have not been extracted yet.

Interoperating set

nixk3s is the ground the siblings stand on: nixgpu shares one GPU by priority on this spine; nixapps is the curated app library that deploys onto it.
